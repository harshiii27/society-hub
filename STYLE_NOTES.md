# Society Hub visual update

This version keeps the existing React routes, backend API calls, authentication, application flow, and admin functionality intact while updating the visual system.

## Visual direction

- Near-black base with warm plum surfaces
- Muted rose as the primary accent
- Small violet accent for depth
- Strong typography and editorial spacing inspired by the supplied TEDx reference
- Homepage receives the strongest entrance and scroll-reveal motion
- Other pages use restrained hover and focus interactions
- Shared design tokens live in `src/index.css`

## Running locally

From the project root:

```bash
npm install
npm run dev
```

The frontend continues to expect the existing backend at `https://society-hub-zsj4.onrender.com`.
